The CLI package is renamed from `@anweba/glugent-cli` to **`glugent`**, so the package name matches the `glugent` command. Install it with `npm i -D glugent` or run it with `npx glugent`. The command, its options and its output are unchanged.

`@anweba/glugent-cli` gets no further releases; replace it with `glugent` in your `package.json`. `@anweba/glugent-core` and `@anweba/glugent-schemas` keep their names.
