# Acme Shop handbook

This handbook is built from the same sections as the agents, so people and agents follow the same rules.

## Team rules

- Work in small pull requests.
- Never commit secrets.
- Leave the code a little better than you found it.

## Reviewing

Read every changed line. Ask for a test when behaviour changes.

## Writing

Keep the docs in step with the code. Prefer examples over long explanations.
